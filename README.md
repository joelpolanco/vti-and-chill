# VTI & Chill 🏔️

**Buy. Hold. Chill.** Financial education platform built on the philosophy that boring investing beats everything else.

## Philosophy

Inspired by JL Collins' *The Simple Path to Wealth* and Paul Merriman's *Sound Investing Portfolios*, VTI & Chill advocates for low-cost index fund investing, staying the course through market volatility, and letting time do the heavy lifting.
